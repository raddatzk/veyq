**Move to…** works the same on a folder, a Memory, a chapter, a file and a drop box.

1. Open the **⋯** menu of the thing, or the buttons at the top of its page, and choose **Move to…**.
2. A window opens where the thing is now, with the path above it (**Where you are**). Click a folder to go into it, or
   a part of the path to go back up.
3. In the place it should go, choose **Move here**. Or choose **Cancel**.
4. A message says where it went and offers **Undo**, which moves it back.

<Screenshot id="depot-move-dialog" shows="The Move dialog with the path above the list of places and the Cancel and Move here buttons" />

Only places that can take the thing are shown. A chapter, for example, only goes into a Memory. **Move here** is greyed
out, with the reason, where it cannot go: into itself, or where it already is. If something with the same name is
already there, veyq says so and nothing moves; rename one of them first.

Everything inside comes along and stays readable. If somebody shared a folder with you and lets you contribute, you can
move things around inside that folder, but not out of it.
