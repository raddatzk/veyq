**Depot** is the place for everything that is not a photo story: contracts, scans, PDFs, spreadsheets, notes, any file you
want to keep safe and find again. You put files in your folders, open them in your browser, and hand them to others
without giving up control. veyq has no sync program for your computer; you upload and download in the browser.

A file in Depot is kept as it is. Whoever you [share](/veyq/sharing/) it with sees the same thing you do. And a
**drop box** lets people without an account send you files, one folder each.

## What you can do

- [Upload files and folders](/veyq/depot/upload-files-and-folders/)
- [Open and look at a file](/veyq/depot/view-a-file/)
- [Replace a file with a newer one](/veyq/depot/replace-a-file/)
- [Rename a file](/veyq/depot/rename-a-file/)
- [Delete a file, and bring it back](/veyq/depot/delete-a-file/)
- [Collect files with a drop box](/veyq/depot/drop-boxes/)

Moving, copying, selecting several, covers, views and favorites work the same for files, folders, Memories and drop
boxes, so they are described once, under [Spaces](/veyq/spaces/).

## Is it private?

A file is locked on your own device before it is uploaded, like a photo. The server cannot read the file or its name.
It sees only that a file exists, roughly how large it is, when it was uploaded or changed, and who in your space may
open it. Details: [Is my data safe?](/veyq/privacy/is-my-data-safe/)
