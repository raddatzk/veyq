1. Open the **⋯** menu of the file's row, or open the file.
2. Choose **Rename**.
3. Type the new **Name**. The selection stops before the file ending, so typing keeps ".pdf" or ".docx".
4. Choose **Save**.

<Screenshot id="depot-rename-dialog" shows="The Rename dialog on a file with the name field and the ending of the name not selected" />

The name has to be free in its folder. If something there already has it, veyq says what and asks you to choose another
name. The file itself is not touched, and everyone who has access sees the new name.
