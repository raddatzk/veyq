## Upload files

1. Open the folder the files should go into.
2. Choose **New**, then **Upload files**, and pick the files. You can also drop files onto the folder.
3. Watch the **Uploads** menu in the top bar. It shows how far each upload is, with one list for each place you upload
   into. A second upload into the same folder joins that list. You can **Cancel** an upload there.

<Screenshot id="depot-upload-menu" shows="The New menu open with Upload files and Upload folder…, and the Uploads menu in the top bar showing one upload in progress" />

Uploads run in the background, so you can keep working.

## Upload a folder

1. Choose **New**, then **Upload folder…**, and pick the folder. You can also drop a folder onto the folder.
2. It arrives as folders and files, just as it is on your computer. Empty folders inside it are left out.

A name that some computers do not allow is changed slightly, and a name that is already taken becomes "Name (2)". If
the folder you pick is an unpacked veyq download, veyq offers to import it instead
([Download and import](/spaces/download-and-import/)).

## When something has the same name

A name has to be free in its folder: a file cannot share a name with a folder, a Memory or a drop box that is already
there. veyq skips that file and tells you which item has the name. If a **file** with the same name is there, veyq
asks whether to replace it ([Replace a file](/depot/replace-a-file/)).

If your space has no room left, veyq says so. Deleted files only free space once they are removed for good from the
[trash](/spaces/trash/).

To get a file back out, see [Open and look at a file](/depot/view-a-file/).
