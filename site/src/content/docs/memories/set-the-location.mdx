A Memory can show **where** it happened, and appear as a pin on the map of your space.

## Turn on maps (once)

The first time you set a location, veyq asks **Enable maps for locations?** A map needs help from outside. Map
pictures are loaded from a map provider, and, if you want a name for a place, the point you chose is sent to a service
that turns it into a name. Both go straight from your device to that provider and never through the veyq server. You
can turn this off again at any time. Choose **Enable maps** to continue, or **Cancel** to leave maps off.

Which map provider and which naming service are used is decided by whoever runs your server. If it uses none, the
space says **This server shows no maps.** and no location can be set; without a naming service you type a place's
name yourself.

## Set a location

1. Open the Memory and choose **Set location** in the header (it says **Edit location** once there is one).
2. A map opens. If your photos were taken with location switched on, it starts at the spot they point to
   (**Follows your photos**). Move the pin if you like; it then says **Your own spot**, and **follow photos** takes it
   back.
3. Give the place a name: type your own ("at grandma's"), or choose **Use the map's name** to let the map service
   suggest one. **Enter your own name** switches back.
4. Choose **Save**. **Remove location** takes the place away again.

<Screenshot id="memories-location-dialog" shows="The Location dialog with the map, the pin, the name field and the Remove location, Cancel and Save buttons" />

Once maps are enabled, the dialog for a new Memory also offers **Determine location automatically**; the place then
follows your photos.

## The map

Memories with a place are pins on the **Map view** of a folder. A Memory without a place is simply not on it.

The place is locked together with the Memory on your device; veyq's server learns neither the place nor the
coordinates. The only thing that ever leaves your device is the point sent to the map provider, and only if you have
enabled maps.
