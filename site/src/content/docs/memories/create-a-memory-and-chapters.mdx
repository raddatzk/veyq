A Memory is one occasion with all its photos and videos. A chapter is a smaller part of it, like one day of a trip.

## Create a Memory

1. Open the folder where the Memory should live.
2. Choose **New**, then **New Memory**.
3. Type a **Name**.
4. Once you have enabled maps, there is also **Determine location automatically**: tick it and the place follows
   where your photos were taken (see [Set the location](/veyq/memories/set-the-location/)).
5. In a space you share with others there is also **I was there**, ticked unless you untick it. It lists you as one of the people who were there ([Say who was there](/veyq/memories/people-in-your-memories/)).
6. Choose **Create**.

<Screenshot id="memories-create-dialog" shows="The Create a Memory dialog with the Name field, the two tick boxes and the Cancel and Create buttons" />

If something with a similar name is already in that folder, veyq tells you and you pick another name.

## Add a chapter

1. Open the Memory and choose the **Chapters** tab.
2. Choose **Add chapter**, type a **Name** and choose **Create**.

A chapter is a little Memory of its own: it has its own photos and its own tabs, and it can have chapters inside it.
Open one from the **Chapters** tab.

<Screenshot id="memories-chapters-tab" shows="The Chapters tab of a Memory with two chapters and the Add chapter tile" />

## Rename, move or delete

The buttons at the top of a Memory or chapter rename, move or delete it. A deleted Memory goes to the trash of your
space and can be restored from there: [The trash](/veyq/spaces/trash/).
