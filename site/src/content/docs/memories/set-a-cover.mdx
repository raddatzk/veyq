A cover is the Memory's face. It shows on the Memory's card, on its page and as its pin on the map.

1. In the folder, open the **⋯** menu of the Memory, or use the buttons at the top of the Memory's page (or the **⋯**
   menu at their end), and choose **Set cover**. It says **Change cover** once there is one.
2. Choose **Choose an image**, pick a picture, and drag and zoom it into the frame.
3. Choose **Save cover**.

<Screenshot id="memories-cover-dialog" shows="The Cover dialog with a picture in the 16:9 frame, the Choose an image button, Remove cover and Save cover" />

If the picture is a photo the gallery of the same Memory or chapter already holds, veyq does not store it a second
time: the cover uses that photo's stored copy, and deleting the photo from the gallery leaves the cover as it is. The
server can then tell which photo is the cover.

To change the framing or the picture, open **Change cover** again. **Remove cover** takes it away. The same window
works for a Memory, a folder and a drop box. Only people who may change the space can set a cover; people you share a
link with see covers but cannot set them.
