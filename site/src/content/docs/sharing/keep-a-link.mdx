Someone sent you a veyq link, from this server or another one. Instead of searching your chats for it later, keep it
as a **bookmark** in a space, next to what it belongs to.

## Keep a link

1. Open the folder where it should live, choose **New** and then **New bookmark**.
2. Paste the whole link. It looks like `https://…/s/…#k=…`; the part after `#k=` is its key, so copy it completely.
3. If the link has a password, enter it too. It is kept with the link, so you do not have to type it again.
4. Give it a name, or keep the one suggested, and choose **Keep link**.

The link and its password are stored **encrypted**, like everything in your space. The server sees that there is a
bookmark, never where it points.

## Who can open it

Everyone who can open this place in the space can open the link and see what it shows. In a space you share with others,
keeping a link there is like forwarding it to them. Keep it in your own space if it is for you alone.

## Open it

Choose the bookmark. Its page shows what the link shares, right there in your space, whether it comes from this server
or another one: browse its folders, and where the link lets you add things, add them as you would on the link's own page.
Before the content, the page asks what the link asks of anyone who opens it: its password (the bookmark enters it for
you), the rules of the space that shared it, and, the first time you add something, the name shown beside it. What you
do there goes straight to the server where the content is stored; this server learns nothing about it.

Some links cannot be shown here: the other server may run another version of veyq or not let its links be shown on other
servers. The page then says why and offers **Open link**: a link of this server opens right here and enters its password
for you; a link of another server opens in a new tab, and if it has a password, you are shown it first so you can copy
it. **Open on its own page** at the top of the bookmark's page does the same at any time. Where showing links in place is
switched off on this server, choosing a bookmark opens its link that way straight away.

If the person who shared it has switched the link off, or it has expired, the page says that the link is not available.
Nothing else changes; delete the bookmark when you no longer need it.

## Report it

If what the link shows should not be there, choose **Report shared content** in the bookmark's menu. The link opens and
asks you what is wrong, as it would ask anyone who opened the link. Your report goes to the people who run **that**
server, the one where the content is stored. **Report name** reports only the name the bookmark has here.

While the bookmark's page shows the content, **Report** on what you see there works the same way: it goes to the server
where that content is stored, as it would from anyone who opened the link.

## What a bookmark does not do

- People you share a folder with through a link do not see your bookmarks in it.
- Downloading or copying a folder leaves its bookmarks out; paste the link again where you need it.
