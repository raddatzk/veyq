You can hand something to anyone, a grandparent, a friend, a group chat, as a **link**. They open it in a browser: no
account, nothing to install. The link shows only what you shared, never the rest of your space, and you can switch it
off at any time.

## What you can share

- **A folder**, with everything in it: files, Memories, further folders.
- **A single file.** The folder it sits in stays private.
- **A Memory**, or one of its chapters.

## Three kinds of links

- **View only**: they can look and download, and change nothing.
- **View + add files** on a folder (on a file: **View + contribute**; on a Memory: **View + add photos**): they can look
  and add their own things. Whether you see this choice depends on your server.
- **Add only**: they can hand things in, but see nothing. On a Memory this is **Add photos only**; on a folder it is
  **Add files only**, which creates a [drop box](/depot/drop-boxes/). Both are chosen under **Share**.

## What you can do

- [Create a link](/sharing/create-a-link/), with a note, a password or an expiry date
- [Ask people to add photos](/sharing/request-uploads/) without letting them see anything
- [Change, switch off, renew and delete links](/sharing/manage-links/)
- [See what a guest sees](/sharing/what-guests-see/)

The key that opens a link sits in the part of the address after the `#`, which a browser never sends to a server. So
people with the link can open what you shared, and the person running the server still cannot. A link cannot be
unseen, though: switching it off stops future access, but not what someone already saved:
[Is my data safe?](/privacy/is-my-data-safe/#when-you-share)

One honest limit: the page that opens a link comes from the veyq server each time, so a link is only as private as
your trust in whoever runs that server. Someone who runs it honestly cannot read along; someone set on it could change
that page. If you run the server yourself, nobody else is in that position: [Known
limitations](/security/known-limitations/#the-operator-served-web-client-is-passive-operator-only)
