1. Öffne den Ordner, die Datei oder die Erinnerung und wähle oben auf der Seite **Teilen**.
2. Wähle **Neuer Link**.
3. Gib dem Link einen **Name**, wenn du magst; nur du siehst ihn.
4. Wähle unter **Was dürfen andere?** **Nur ansehen** oder die Wahl, mit der man auch etwas hinzufügen kann: bei einem
   Ordner **Ansehen + Dateien hinzufügen**, bei einer Datei **Ansehen + mitwirken**, bei einer Erinnerung **Ansehen +
   Fotos hinzufügen**. Bei einer Erinnerung gibt es außerdem **Nur Fotos hinzufügen** für einen
   [Upload-Link](/de/sharing/request-uploads/), bei einem Ordner **Nur Dateien hinzufügen**, das einen
   [Briefkasten](/de/depot/drop-boxes/) anlegt. Du siehst nur die Möglichkeiten, die dein Server erlaubt.
5. Füge, wenn du magst, etwas davon hinzu:
   - **Hinweis**: eine Nachricht für alle, die den Link öffnen. Schreib sie je Sprache mit **Bearbeiten**. Setze den
     Haken bei **Muss vor dem Öffnen akzeptiert werden**, wenn man sie zuerst lesen und akzeptieren soll.
   - **Passwortschutz**: Der Link öffnet sich nur mit einem Passwort ab 10 Zeichen. Gib es auf einem anderen Weg weiter
     als den Link selbst.
     Das Passwort prüft der Server, es steckt nicht in der Verschlüsselung: Es hält so weit, wie du der Person
     vertraust, die den Server betreibt, ganz, wenn du das selbst bist. Verschlüsselt bleibt, was du geteilt hast, so
     oder so.
   - **Ablaufdatum**: Der Link funktioniert nach diesem Tag nicht mehr.

   Dein Bereich kann für jeden Link ein Passwort oder ein Enddatum innerhalb einiger Tage verlangen. Das Formular hat
   den Abschnitt dann schon eingeschaltet und sagt es dazu, und der Kalender bietet keinen späteren Tag an.
6. Wähle **Link erstellen**, dann **Link kopieren**, und schick ihn weiter.

## Was ein Link zum Ansehen und Hinzufügen erlaubt

- **Bei einem Ordner** (**Ansehen + Dateien hinzufügen**): Gäste können Ordner anlegen und Dateien hochladen, eine neuere Fassung über eine Datei legen
  (veyq warnt, dass es keinen Versionsverlauf gibt) und Dinge innerhalb des geteilten Ordners verschieben. Löschen oder
  umbenennen können sie nichts, und eine Erinnerung oder einen Briefkasten können sie nicht anlegen.
- **Bei einer Erinnerung** (**Ansehen + Fotos hinzufügen**): Gäste können Fotos und Videos hinzufügen und ihre eigenen wieder löschen.
- **Bei einer einzelnen Datei** (**Ansehen + mitwirken**): Gäste können sie ansehen, herunterladen und eine neuere Fassung an ihre Stelle legen.
  veyq warnt vorher, dass sich die Datei für alle ändert, die den Link haben, auch für dich, und dass sich der alte
  Inhalt nicht zurückholen lässt.

Gäste, die etwas hinzufügen, nennen einmal ihren Namen, damit du siehst, wer was hinzugefügt hat. Andere Gäste sehen ihn
nie. Was Gäste hinzufügen, zählt zum Speicher deines Bereichs, bis zu einer Grenze pro Link, die die Person festlegt, der
der Bereich gehört ([Speicher](/de/space-owners/storage/)).

Alles, was du schreibst, auch der Hinweis, wird verschlossen, bevor es dein Gerät verlässt; nur wer den Link hat, kann es
lesen, und der Server weiß nicht einmal, ob ein Link um Zustimmung zu einem Hinweis bittet:
[Sind meine Daten sicher?](/de/privacy/is-my-data-safe/)
