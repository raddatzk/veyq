Du kannst jemandem etwas als **Link** geben, Großeltern, einer Freundin, einem Gruppenchat. Geöffnet wird er im
Browser: ohne Konto, ohne Installation. Der Link zeigt nur, was du geteilt hast, nie den Rest deines Bereichs, und du
kannst ihn jederzeit abschalten.

## Was du teilen kannst

- **Einen Ordner**, mit allem darin: Dateien, Erinnerungen, weitere Ordner.
- **Eine einzelne Datei.** Der Ordner, in dem sie liegt, bleibt privat.
- **Eine Erinnerung** oder eines ihrer Kapitel.

## Drei Arten von Links

- **Nur ansehen**: Man kann schauen und herunterladen und nichts ändern.
- **Ansehen + mitwirken** (bei einer Erinnerung: **Ansehen + Fotos hinzufügen**): Man kann schauen und Eigenes
  hinzufügen. Ob du diese Wahl siehst, hängt von deinem Server ab.
- **Nur hinzufügen**: Man kann etwas abgeben, sieht aber nichts. Bei einer Erinnerung ist das **Upload anfragen**; für
  Dateien ist es ein [Briefkasten](/veyq/de/depot/drop-boxes/).

## Was du tun kannst

- [Einen Link erstellen](/veyq/de/sharing/create-a-link/), mit Hinweis, Passwort oder Ablaufdatum
- [Menschen Fotos hinzufügen lassen](/veyq/de/sharing/request-uploads/), ohne dass sie etwas sehen
- [Links ändern, abschalten, erneuern und löschen](/veyq/de/sharing/manage-links/)
- [Sehen, was ein Gast sieht](/veyq/de/sharing/what-guests-see/)

Der Schlüssel, der einen Link öffnet, steckt im Teil der Adresse nach dem `#`, den ein Browser nie an einen Server
schickt. Wer den Link hat, kann öffnen, was du geteilt hast, die Person, die den Server betreibt, aber nicht. Ungesehen
machen lässt sich ein Link allerdings nicht: Abschalten stoppt den künftigen Zugriff, aber nicht, was jemand schon
gespeichert hat: [Sind meine Daten sicher?](/veyq/de/privacy/is-my-data-safe/)
