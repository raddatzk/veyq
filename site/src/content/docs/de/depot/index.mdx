**Depot** ist der Ort für alles, was keine Foto-Geschichte ist: Verträge, Scans, PDFs, Tabellen, Notizen, jede Datei, die
du sicher aufbewahren und wiederfinden willst. Du legst Dateien in deine Ordner, öffnest sie im Browser und gibst sie an
andere weiter, ohne die Kontrolle abzugeben. veyq hat kein Programm, das deinen Computer abgleicht; du lädst im Browser
hoch und herunter.

Eine Datei im Depot bleibt, wie sie ist. Wem du sie [teilst](/veyq/de/sharing/), der sieht dasselbe wie du. Und ein
**Briefkasten** lässt Menschen ohne Konto dir Dateien schicken, jede Person in einem eigenen Ordner.

und Briefkästen genauso; sie stehen deshalb einmal, unter [Bereiche](/veyq/de/spaces/).

## Ist das privat?

Eine Datei wird auf deinem eigenen Gerät verschlüsselt, bevor sie hochgeladen wird, wie ein Foto. Der Server kann weder
die Datei noch ihren Namen lesen. Er sieht nur, dass es eine Datei gibt, ungefähr wie groß sie ist, wann sie hochgeladen
oder geändert wurde und wer in deinem Bereich sie öffnen darf. Mehr dazu:
[Sind meine Daten sicher?](/veyq/de/privacy/is-my-data-safe/)
