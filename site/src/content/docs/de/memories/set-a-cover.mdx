Das Cover ist das Gesicht der Erinnerung. Es erscheint auf ihrer Karte, auf ihrer Seite und als ihr Pin auf der Karte.

1. Öffne im Ordner das **⋯**-Menü der Erinnerung oder nutze die Schaltflächen oben auf ihrer Seite und wähle **Cover
   festlegen**. Dort steht **Cover ändern**, sobald es eines gibt.
2. Wähle **Bild auswählen**, such ein Bild aus und ziehe und zoome es in den Ausschnitt.
3. Wähle **Cover speichern**.

<Screenshot id="memories-cover-dialog" shows="Der Dialog Cover mit einem Bild im 16:9-Ausschnitt, der Schaltfläche Bild auswählen, Cover entfernen und Cover speichern" />

Ist das Bild ein Foto, das die Galerie derselben Erinnerung oder desselben Kapitels schon enthält, speichert veyq es
nicht ein zweites Mal: Das Cover nutzt die gespeicherte Kopie dieses Fotos, und löschst du das Foto aus der Galerie,
bleibt das Cover, wie es ist. Der Server kann dann erkennen, welches Foto das Cover ist.

Um Ausschnitt oder Bild zu ändern, öffne **Cover ändern** noch einmal. **Cover entfernen** nimmt es weg. Dasselbe Fenster
gilt für eine Erinnerung, einen Ordner und einen Briefkasten. Ein Cover festlegen können nur Menschen, die den Bereich
ändern dürfen; wer nur einen Link hat, sieht Cover, kann aber keine festlegen.
