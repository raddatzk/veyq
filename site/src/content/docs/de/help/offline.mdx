## „Dieser Bereich ist vorübergehend offline“

Wer deinen Server betreibt, hat deinen Bereich vorübergehend offline genommen, zum Beispiel, um einer Meldung
nachzugehen. Seine Inhalte sind sicher und unverändert; er lässt sich nur gerade nicht öffnen, weder von Mitgliedern
noch über Links. Sobald er wieder da ist, ist alles, wo du es gelassen hast. Gehörst du zu mehr als einem Bereich,
markiert der Bereichswechsler diesen mit **Vorübergehend offline**. Frag die Person, die deinen Server betreibt, wann
er zurück ist.

Ein Bereich, der gelöscht wird, sieht genauso aus. Dann hast du auch eine E-Mail bekommen, die das sagt und das Datum
nennt: An diesem Tag wird alles im Bereich gelöscht, wenn die Person, die deinen Server betreibt, die Löschung nicht
vorher stoppt. Dein Konto bleibt, und deine anderen Bereiche auch.

## „Dieser Server ist gerade nicht erreichbar“

veyq kann nicht mit seinem Server sprechen: Deine Internetverbindung ist weg, oder der Server ist es. Prüfe deine
Verbindung und versuch es später erneut. Auf deinem Gerät geht nichts verloren; deine Schlüssel bleiben, wo sie waren.

## „Dieser Server ist noch nicht eingerichtet“

Auf diesem Server wurde noch kein erstes Konto angelegt, es gibt also nichts, wo du dich anmelden könntest. Eingerichtet
wird der Server von der Person, die ihn betreibt, auf seiner eigenen Verwaltungsoberfläche, nicht auf dieser Seite. Hat
dir jemand diese Adresse geschickt, ist es vielleicht die falsche.

Einen Bereich offline zu nehmen, öffnet ihn niemandem: Die Person, die den Server betreibt, kann weiterhin nicht lesen,
was darin liegt: [Sind meine Daten sicher?](/de/privacy/is-my-data-safe/)
