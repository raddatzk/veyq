An **application** is one kind of sealed thing you can keep in your spaces. veyq has two:

| | **Memories** | **Depot** |
|---|---|---|
| For | Photos, videos and the occasions they belong to: a trip, a wedding, a birthday | Documents, PDFs and any other file you want to keep |
| You keep | Memories, with chapters | Files, and drop boxes that collect files from others |
| Start here | [Memories](/veyq/memories/) | [Depot](/veyq/depot/) |

Both live side by side in the same folders of your space. A folder can hold a Memory, a file and a drop box at the
same time, and the same things work on all of them: you can rename, move, copy and delete them, give them a cover,
mark them as favorites and [share](/veyq/sharing/) them.

<Screenshot id="applications-one-folder" shows="A folder that holds a Memory, a file and a drop box together, in list view, with the tabs All, Memories, Depot and Drop boxes above the list" />

The tabs above the list — **All**, **Memories**, **Depot**, **Drop boxes** — show just one kind at a time. Folders stay
visible in every tab, so you can keep moving through your space.

Everything you keep in either application is locked on your device before it leaves it. What the server can and
cannot see is the same for both: [Is my data safe?](/veyq/privacy/is-my-data-safe/)
