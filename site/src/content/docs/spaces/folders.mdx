## Create a folder

1. Open the place the folder should go in.
2. Choose **New**, then **New folder**.
3. Enter a **Name** and choose **Create**.

<Screenshot id="spaces-new-menu" shows="A folder with the New menu open: New folder, New Memory, Upload files, Upload folder… and New Pot" />

If something with a similar name is already there, veyq says so; choose another name.

## Rename or delete a folder

Open the folder. To rename it, click its name at the top: the name turns into a field. **Move to…** and **Delete** are in
the **⋯** menu at the end of the buttons beside the name.

- **Rename:** type the new name and press Enter (Esc keeps the old one). If the name is taken here, veyq says so under the
  field.
- **Delete:** confirm with **Delete**. The folder and everything inside it move to the [trash](/veyq/spaces/trash/),
  and a message offers **Undo** for a few seconds.

A folder's row in the list offers the same in its **More actions** menu: **Rename**, **Move to…** and **Delete**. To
delete several things at once, use [Select](/veyq/spaces/select-several/).

Folder names are locked on your device like everything else; the server only sees that a folder exists:
